server
--------------------------
setup:

$ npm init -y

$ npm i express

install nodemon

$ npm i nodemon -D

update package.json with:
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "start": "node server",
    "dev": "nodemon server"
  },

also, to be able to import the shared library:
  "type": "module",
